# Voice Leveler

YouTubeやXなどのトーク配信で、話し声らしい区間を検出し、タブの再生音量を滑らかに調整するChrome拡張です。

音声分離や話者識別は行いません。混ざった音声全体の音量を調整するため、BGMも影響を受けます。音楽や効果音を話し声と誤判定する場合があります。

## インストール

Chrome 116以降が必要です。現在はChromeウェブストアからのインストールには対応していません。

1. このリポジトリをクローンするか、GitHubの「Code」からZIPをダウンロードして展開します。
2. Chromeで `chrome://extensions` を開き、デベロッパーモードを有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」を押し、`manifest.json` があるフォルダを選びます。

## 使い方

1. 音声を再生するページを開き、拡張機能のアイコンをクリックします。
2. ポップアップの「処理を開始」を押します。
3. 必要に応じて補正強度、話し声判定の感度、最大増幅・減衰、BGM抑制を調整します。設定はサイトのホスト名ごとに保存されます。
4. 「処理を停止」を押すと通常の再生に戻ります。

開始にはユーザー操作が必要です。処理できるのは選択したChromeタブの音声です。

## プライバシーと権限

音声はブラウザ内で処理し、外部へ送信しません。設定はブラウザのローカルストレージに保存します。

- `activeTab`：操作対象のタブを取得します。
- `tabCapture`：対象タブの音声を取得します。
- `offscreen`：ポップアップを閉じた後も音声を処理して再生します。
- `storage`：サイトごとの設定と処理状態を保存します。

## 開発・テスト

Node.js 20以降で次を実行します。依存パッケージのインストールやビルドは不要です。

```sh
npm test
```

手元の音声ファイルを解析する場合は、`ffmpeg` をPATHに用意してファイルを指定します。音声ファイルはリポジトリに含まれません。

```sh
npm run analyze:sample -- path/to/audio.mp3
```

自動テストは音声判定の一部を検証します。実際の配信での音質や動作は環境によって異なります。
